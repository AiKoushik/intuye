# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately through GitHub instead, from the **Security** tab of this repository, **Report a vulnerability**, or directly at
[github.com/AiKoushik/intuye/security/advisories/new](https://github.com/AiKoushik/intuye/security/advisories/new).

Include what you found, how to reproduce it, and what someone could do with it. You'll get a reply within a week. Please give a reasonable time to fix it before talking about it publicly.

## What counts

Anything that lets someone read or change another learner's data, get past Sign in with Apple, sessions or App Attest, make the agents follow instructions hidden in learner text or library scenes, expose captured audio or sentences, or reach personal details in shared scenes.

## Supported versions

Only the latest release and the `develop` branch get security fixes while Intuye is before 1.0.

The security design is described in [`docs/06-security.md`](docs/06-security.md).
